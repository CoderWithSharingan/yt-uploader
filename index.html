Clip Uploader – Privacy Policy

Last updated: 18 November 2026

Clip Uploader is a personal command-line tool that I, Harshit Nair, use to upload short videos I have edited to my own YouTube channel. It is used only by me and is not offered to any other users.

Use of YouTube API Services

Clip Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

The tool requests one Google OAuth scope: https://www.googleapis.com/auth/youtube.upload. It uses this only to upload a video file chosen by me, with a title, description, tags, category, privacy status and optional publish time that I provide. It does not read, collect or store any other data from my Google account or YouTube channel, and it does not access any other person's data.

How data is stored

The OAuth access and refresh token is saved in a local file (token.json) on my own computer so I do not have to sign in every time. Video files and descriptions stay on my computer until I upload them to YouTube. The tool has no server, database, analytics or tracking, and sends data only to Google's APIs.

How data is shared

No data is sold or shared with any third party. The only data sent anywhere is the video and its details, sent to YouTube through the YouTube Data API at my request.

Deleting data and revoking access

Access can be revoked at any time on the Google security settings page. Deleting token.json removes the stored token from the computer. Uploaded videos can be deleted in YouTube Studio.
